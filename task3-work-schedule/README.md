# Task 3: Work Schedule

## Что нужно

Из списка WorkSheet вывести дни, в которые работает больше одного человека.

## Как решал

- Развернул список "человек -> дни" в "день -> количество людей"
- Через flatMap получил плоский поток дней
- Сгруппировал через groupingBy + counting
- Отфильтровал дни, где count > 1

## Запуск

mvn compile exec:java

## Что выводит

WEDNESDAY (2)
THURSDAY (2)
